# Prompt Patterns

Use these patterns when the user wants repeatable prompt packs or needs variants for different generation tools.

## Character Reference

Build a neutral, repeatable identity image.

```text
[aspect ratio] character reference portrait of [name/role], [age], [body/face anchors], [hair/skin/eyes], wearing [costume], holding/wearing [signature prop], neutral readable background, soft controlled lighting, front three-quarter view, sharp facial detail, consistent identity anchor, no text, no logo
```

## Cinematic Scene Still

Use for story moments and film frames.

```text
[aspect ratio] cinematic film still, [subject] in [location], [visible action], [physical emotion], [screen placement and depth], [camera angle and lens], [motivated lighting source], [color palette], [atmosphere/weather], [production design details], realistic texture, controlled depth of field, continuity locked
```

## Poster / Thumbnail

Use one readable idea and strong silhouette.

```text
[aspect ratio] high-impact poster image for [story/topic], [main subject] positioned [composition], [symbolic object or background conflict], bold readable silhouette, strong contrast lighting, clean negative space for title text, limited palette of [colors], premium cinematic finish, no actual text
```

## Location Reference

Prioritize geography and repeatable details.

```text
[aspect ratio] environment reference of [location], [time period], [layout], [key props/landmarks], [materials and textures], [time of day], [light direction], wide establishing view, no people unless requested, repeatable production-design details
```

## Image-to-Video Keyframe

Make the frame stable, with one obvious motion path.

```text
[aspect ratio] first frame for image-to-video, [subject] frozen at the start of [single action], [body position/contact points], [screen placement], [camera position], [lighting], [environment], motion potential visible in [fabric/hair/smoke/rain/vehicle/door], final frame should preserve [continuity lock]
```

## Negative Prompt Starter

```text
wrong identity, inconsistent face, extra fingers, extra limbs, distorted hands, duplicated person, warped anatomy, unreadable eyes, blurry face, random text, watermark, logo, overexposed skin, plastic texture, mismatched costume, changed location, cluttered composition
```
